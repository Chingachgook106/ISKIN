# EXP-001. Выбор эталонной открытой LLM для экспериментального стенда

## Цель

Выбрать наиболее подходящую открытую языковую модель (Open Source LLM) в качестве базового эталона для инженерного экспериментального стенда.

Исследование не направлено на поиск самой мощной или самой современной модели. Необходимо определить модель, наиболее подходящую для детального изучения, воспроизводимых экспериментов и последующих контролируемых модификаций.

---

## Задача

Выступите в роли независимого инженера-исследователя.

Не предлагайте собственную архитектуру модели.

Не оценивайте качество генерации текста.

Не ориентируйтесь на популярность проекта.

Не учитывайте коммерческий успех.

Оценивайте исключительно инженерскую пригодность модели как лабораторного объекта исследования.

---

## Кандидаты

Рассмотрите следующие семейства моделей:

- Llama
- OLMo
- Mistral
- Qwen
- Gemma
- Falcon

Если существуют другие открытые модели, превосходящие перечисленные по инженерным характеристикам, включите их в анализ.

---

## Критерии оценки

Для каждой модели оцените:

1. Открытость архитектуры.
2. Доступность весов модели.
3. Полноту технической документации.
4. Документированность процесса обучения.
5. Документированность токенизатора.
6. Документированность механизма внимания.
7. Возможность локального запуска.
8. Возможность локальной модификации компонентов.
9. Возможность отключения или замены отдельных механизмов.
10. Наличие инженерных инструментов исследования внутренних механизмов модели.
11. Воспроизводимость результатов.
12. Размер и активность исследовательского сообщества.
13. Долговременную поддержку проекта.
14. Пригодность модели в качестве экспериментального стенда.

---

## Формат ответа

Для каждой модели необходимо представить:

- краткое описание;
- сильные стороны;
- слабые стороны;
- ограничения;
- возможные инженерные риски;
- общую оценку.

После этого необходимо построить сравнительную таблицу.

---

## Итоговый анализ

В заключение ответьте на следующие вопросы:

1. Какая модель наиболее подходит в качестве эталонной инженерной платформы?

2. Почему именно она?

3. Какая модель занимает второе место?

4. Какие критерии выбора, по вашему мнению, отсутствуют в данном исследовании?

5. Какие потенциальные проблемы могут возникнуть при использовании выбранной модели в качестве долгосрочного экспериментального стенда?

---

## Требования

Все выводы должны сопровождаться инженерской аргументацией.

Если используются общепринятые сведения, укажите их происхождение (официальная документация, технические статьи, публикации разработчиков и т.п.).

При наличии неопределённостей укажите их явно.

Не делайте предположений без достаточных оснований.
